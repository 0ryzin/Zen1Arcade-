# Zen1 Arcade compatibility list

Generated by `tools/gen_compatibility.py` from the engine's own game list.
**Supported** means the hardware is implemented in Zen1 and the ROM set is
recognised. It does not mean the game has been played: the **Tested** column
says No until someone has run that game on Zen1 with a real ROM set.
The Zen1 project does not distribute ROMs or BIOS files.
